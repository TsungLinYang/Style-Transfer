# Overview
This project allows users to transform the style of images captured by a camera in real time. Users can select multipe styles, such as one inspired by Vincent van Gogh or Pablo Picasso. Once  style images are uploaded and the camera is activated, the system captures the characteristics of the style image and applies them to the live camera feed.

Additionally,we have a hand gesture recognition feature. Users can simply make a "Ya" gesture to automatically take a photo, or show a "Five" gesture to switch between different styles.
